STAGE LYRICS — installatie en gebruik

INHOUD
Deze map bevat de complete gratis PWA. Er zijn geen abonnementen, advertenties of accounts ingebouwd. Setlists en songteksten worden lokaal in de browser van het apparaat opgeslagen.

BELANGRIJK
Voor installatie als app en offline gebruik moet de map op een HTTPS-webadres staan. Openen als lokaal bestand (index.html) is alleen bedoeld om de pagina te bekijken; PWA-installatie en offline caching werken dan niet betrouwbaar.

GRATIS PUBLICEREN VIA GITHUB PAGES
1. Maak gratis een account op https://github.com als je dat nog niet hebt.
2. Maak een nieuw PUBLIC repository aan, bijvoorbeeld stage-lyrics.
3. Upload alle bestanden uit deze map naar de hoofdmap van de repository.
4. Ga in de repository naar Settings → Pages.
5. Kies bij Build and deployment: Deploy from a branch. Selecteer branch main en map /(root), klik Save.
6. Na publicatie geeft GitHub Pages een HTTPS-adres, meestal https://JOUW-GEBRUIKERSNAAM.github.io/stage-lyrics/
7. Open dat adres op de Android-tablet in Chrome of op de iPad in Safari.

INSTALLEREN
Android: open de site in Chrome → menu ⋮ → Install app of Toevoegen aan startscherm.
iPad: open de site in Safari → Deel-knop → Zet op beginscherm.

GEBRUIK
- Maak een setlist met + bij Setlists.
- Maak nummers met + bij Songs; plak de songtekst en sla op.
- Tik op een nummer om de tekst te tonen.
- Gebruik Edit om titel of tekst te wijzigen.
- Stage mode toont de tekst schermvullend. Start scrolling en stel de snelheid in.
- Gegevens blijven op het apparaat waarop ze zijn ingevoerd. Ze worden niet automatisch gesynchroniseerd met andere apparaten.

PRIVACY / BACK-UP
De app stuurt geen songteksten naar een server. Wis de browsergegevens niet zonder eerst zelf een back-up te maken. Voor nu is er geen ingebouwde export/importfunctie.

COMPATIBILITEIT
Ontworpen voor moderne Android Chrome en iPad Safari. Scherm wakker houden en fullscreen zijn afhankelijk van browser- en apparaatondersteuning.
